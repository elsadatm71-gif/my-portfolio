## Project Overview

A modular autonomous-driving stack developed using ROS 2 Humble and CARLA, combining navigation, perception, vehicle control and safety systems.

## Main Features

✅ CARLA integration with ROS 2  
✅ Camera, LiDAR, radar, GPS and vehicle-state sensors  
✅ Lanelet2 HD-map destination routing  
✅ Curvature-based speed planning  
✅ Pure-pursuit path tracking  
✅ PI cruise control  
✅ Camera lane detection  
✅ Physical road-edge detection  
✅ Bird's-eye-view transformation  
✅ LiDAR obstacle detection  
✅ Radar object tracking  
✅ Multi-sensor automatic emergency braking  
✅ Steering safety watchdog  
✅ OpenDRIVE-to-Lanelet2 map conversion  

## Technologies

ROS 2 • CARLA • C++ • Python • OpenCV • Lanelet2 • LiDAR • Radar • RViz • Linux • Git
